# ALFA Visual Intelligence v1.0 --- Quick Reference

**Use this for normal visual work. Consult the Master for new
directions, conflicts, major transformations, generic-output diagnosis,
or changes to Visual Intelligence.**

*Derived from the canonical Master [`ALFA_VISUAL_INTELLIGENCE_v1.0.md`](ALFA_VISUAL_INTELLIGENCE_v1.0.md). If they ever differ, the Master wins.*

## Master rule

**Alfa has no fixed visual style. Derive the visual language from the
current brand. The revelation---not the shader---is the effect.**

## Required sequence

Business Context → Brand Essence → Emotion → Visual Thesis → WOW
Governor → Static A/B → **Human Static Gate** → Signature Moment →
Anchor/Ancestry → Transformation Grammar → Conflict Resolver →
Anti-Generic → Technical Intelligence → Motion Proof → Engineering Gate
→ **Human WOW Gate**.

## Before art direction

Complete: **"This brand exists to \_\_\_\_\_\_\_\_, in a differentiated
way through \_\_\_\_\_\_\_\_, and people should feel
\_\_\_\_\_\_\_\_."**

Separate known facts, interpretations, creative hypotheses and
assumptions. Do not invent certainty.

## Core rules

-   Emotion before effect.
-   Static First: weak endpoints do not get animated.
-   One primary Signature Moment is usually stronger than constant
    spectacle.
-   WOW is governed, not maximized.
-   Attention is finite: one dominant event at a time.
-   Target retrospectively coherent surprise: unexpected, then
    inevitable.
-   Preserve meaningful information through transformations.
-   Maintain a Perceptual Anchor.
-   Define what in A becomes what in B with an Ancestry Map when
    relevant.
-   Motion requires causality: **cause → anticipation → reaction →
    consequence → settle**.
-   Technical complexity may be high; perceptual complexity must remain
    controlled.
-   Camera moves only when it reveals useful spatial/narrative truth.
-   Content/product truth outranks metaphor.

## Fidelity checks

Composition / Material / Lighting / Structural Transformation /
Transition / Motion / Spatiality / Hierarchy / Causality / Narrative /
Anchor.

## Conflict priority

**Purpose → Comprehension → Identity → Delight → Technical Spectacle**

If spectacle conflicts with the commercial/user objective, the objective
wins.

## Restraint Gate

For every decorative/spectacular element: **What meaningful value is
lost if this is removed?** If the answer is only "cooler", "more
premium", or "shows skill", remove or justify it.

## Anti-Generic tests

-   Logo Swap
-   Direct Competitor Swap
-   **Nearest-Competitor Swap**
-   Industry Swap
-   Remove-the-Effect
-   Explain Why: "This moment exists because this brand \_\_\_\_\_\_."
-   Technique Substitution
-   Alfa-Style Detection

If the closest competitor can use the same thesis/signature moment
unchanged, refine Brand Essence.

## High-risk defaults

Particles, vortexes, glowing shards, sci-fi neon, random glass cracks,
arbitrary liquefaction, bloom-as-quality, RGB split, defect-hiding
grain, crossfades, shader demos, flying-object spectacle, opacity-only
transforms, meaningless typography spectacle, post-processing makeup,
generic procedural worlds.

Not forbidden; they must be earned by the concept.

## Failure modes

Demo Syndrome / Plugin Syndrome / Screensaver Syndrome / Shader Porn /
Transition Tunnel / Everything Moves / Fake Physics / Procedural
Genericness / Post-processing Makeup / Technical Flex / Desktop Illusion
/ WOW Fatigue / Premium-Shorthand Trap.

## Freeze-frame protocol

Inspect meaningful states around: **0 / 10 / 25 / 37 / 50 / 63 / 75 / 90
/ 100%** and explicitly find the **worst frame**.

## Responsive / accessibility

Preserve in order: 1. meaning; 2. hierarchy; 3. anchor; 4. causality; 5.
key information.

Reduce fidelity before reducing the idea. Motion cannot be the sole
carrier of meaning. Reduced/static versions must express the same
concept.

## Human gates

AI can build, render, inspect and critique. It cannot self-certify WOW.

**Engineering PASS + Art Direction FAIL = FAIL.**

Hard gates: A Brand → B Thesis → C Static → D Identity → E
Transformation → F Motion → G Engineering → H Human WOW.

## Lessons already paid for

-   Round 1: sophisticated effect ≠ semantic transformation.
-   Round 2: more effects ≠ more WOW; compute cannot repair weak art
    direction.
-   Flagship 01: spatial reinterpretation works, but technical proof ≠
    premium art-direction proof.
-   Experiment 02: strong ancestry works; endpoint art direction can
    still cap the result.
-   Current bottleneck: **Static Art Direction quality before motion.**

## Correct relationship with Technical Intelligence

**Visual Intelligence = WHAT + WHY.** **Technical Visual Intelligence =
HOW.**

Never start with an interesting technique and invent brand justification
afterward.
