## Implemented architecture

Canonical layer: `alfa/gi-visual-lab/v0.1/`. Run namespace: `experiments/alfa-gi-visual-lab-v0.1/runs/<experiment-id>/`.

GI responsibilities materialized as executable orchestration/scaffold, current-phase context compiler, deterministic capped knowledge router, phase governance and stop/evidence guidance. The model/operator still performs creative search and site generation. Early phases receive no mechanism dump. Project Truth requires sourced facts and explicit unknowns; blocked Truth prevents run initialization. Experience Promise and signature/concept fields begin unfilled, avoiding invented project claims or automatic style selection.

Six procedural Visual Lab units implement: governed environment travel; meaningful motion vs noise; pointer response balance; fast-scroll flashing/skipping; transformation readability; preserve agency/spectacle during repair. Each unit has implementation patterns, sourced examples, anti-examples, failures, tests, repairs, invariants, costs and unproven transfer status. No copied universal implementation constants or house-style recipe.

HEG is diagnostic/test/repair guidance. TEG is its transition failure subset. Each sourced observation yields relevant tests, repair strategies, preserve invariants and BEFORE/AFTER gates for DEFECT REDUCED plus VALUE PRESERVED. No automated visual repair, quality metric or Human certification is claimed. Native document controls and environment response remain distinct; technical performance cannot certify perceptual continuity.

Active-context/intake/unit/diagnostic/trace/evidence/prediction/Human Review contracts are explicit JSON Schema definitions checked by a strict dependency-free local subset validator. Trace separates activation from changed decisions and permits model-native/unchanged outcomes. Evidence labels and authority remain separate; the CLI refuses controlled-contribution self-certification.

Guided runs contain exclusive input/context/prompt records and a hashed snapshot of runtime, contracts, governance and knowledge. Output cannot automatically write back to candidate. Baseline receives only common task inputs, no ALFA knowledge/prompt rules/snapshot. Pair creation matches declared model/settings/brief/truth/promise/assets/tools/budget/evaluation; comparison rejects mismatches and reports the arms separately without inventing contribution.

Pre-review predictions are write-once and bound to the actual artifact manifest. Human Review requires an explicit operator-attested input after freezing; it remains a separate evaluator record. Review packages hide model/prediction text but require operator anonymization for true blindness. Technical records cannot stand in for Premium/WOW/Would Pay/UX Motion Quality.

## Limits, hypotheses and next step

The CLI is a manual model adapter, not an autonomous model runner or renderer. Routing is a transparent finite-vocabulary coverage heuristic, not semantic inference or an exact token optimizer. Schemas cannot establish factual truth. Budgets/permissions/evaluation match by declaration; actual enforcement, execution accounting, independent sessions and review blinding require the operator/tool sandbox. Human-input attestation is not identity verification. Exclusive writes/hashes detect accidental edits, not malicious resealing or cross-process races. Partial initialization is preserved for inspection; no destructive retry/recovery or automatic learning/promotion exists.

Useful ambition, reduced template convergence, knowledge usefulness, preservation of agency/spectacle during repair, cross-domain generalization and cheaper-model contribution remain untested hypotheses. Preserve original VELORUM versus refinement as separate evidence: technical improvements did not erase weaker human impact or PARTIAL UX Motion Quality. Engineering PASS is not an art/experience PASS.
